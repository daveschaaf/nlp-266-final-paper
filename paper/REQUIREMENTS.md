# Report requirements

Source: supplied `guidelines/README.pdf`. Course requirements take precedence
over conference-specific instructions in the example template.

- Aim for 4–6 pages, in research-paper style.
- Suggested sections: Abstract; Introduction; Background/Related Work; Methods;
  Results and Discussion; Conclusion.
- Explain the problem, baseline, measurable objective, methodology, iterations,
  findings, and comparison with relevant literature.
- Include plots/figures and substantive analysis where appropriate.
- Submit a PDF and project code through the course/team GitHub repository and
  complete the course submission form; follow section-instructor instructions.
- Presentation: approximately six minutes.
- Teams of two or three must include author contributions; each member must
  work on at least one model.
- Rubric: overall themes 10%; crisp objective 20%; methodology and analysis 50%;
  technical communication 20%.

## Supplied LaTeX materials

Original files are preserved in `template/`, including the sample source/PDF,
style, bibliography style, and example bibliographies. They are reference
materials, not a draft of this project's report.

- Recommended engine: pdfLaTeX.
- Document class: 11pt article; ACL two-column style.
- The example uses review mode (anonymous author and line numbers). Remove the
  review option for an identified final version unless the instructor requests it.
- The source loads `ACL2023` while the supplied filename is `acl2023.sty`.
  Match the filename case when preparing the actual manuscript for portability.
- Citations use natbib (`\citet`, `\citep`) and `acl_natbib` bibliography style.
- The conference template describes Limitations and Ethics sections and its own
  page-limit rules. These are conference instructions, not independently stated
  course requirements. Do not substitute conference limits for the course's
  4–6-page target.

Unspecified: whether references/appendices count toward the course page target.
